# Campaign 3 Phase 12 — sidebar navigation

**Status:** Complete and accepted.

The sidebar starts with one full-width **New conversation** action. Workspace, the sidebar username, and the old Files/+ New pair are removed. Conversation history scrolls independently below the primary action.

**My Files** lives in the top bar as an accented folder action, separated by space and a divider from username, Admin Panel, and Log out. The app shell owns its dialog, so file access does not depend on the conversation model catalog loading.

Conversation creation, empty-draft cleanup, search, active/archive views, rename, archive/restore, deletion, keyboard focus, and narrow-screen layouts retain their existing behavior.
