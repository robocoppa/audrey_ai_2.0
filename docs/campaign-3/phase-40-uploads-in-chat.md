# Campaign 3 Phase 40 — Finding and scoping owned files

**Closed 2026-10-27.** Historical contract; see the [campaign index](README.md).

`list_my_files` lets models discover real owned file identities before requesting
scoped retrieval. A named-file question can constrain `kb_search` to that file
and artifact; plural and comparison questions must retain the appropriate wider
scope. The authenticated pipeline user controls every query.

File rows expose processing state and elapsed time while work runs. The native
file/composer surfaces in Campaign 4 supersede the external UI upload banner.
The narrow [video role](phase-42-video-specialist.md) concerns retrieval behavior,
not a separate upload or media-processing pipeline.
