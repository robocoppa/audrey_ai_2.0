# Campaign 3 Phase 42 — Video retrieval role

**Closed 2026-10-27.** Historical contract; see the [campaign index](README.md).

The adaptive video virtual model supplies a small task role for using the
existing file/retrieval tools. Tool descriptions already teach listing and scoped
search, so the role must not duplicate a large instruction set or imply different
ownership/ingest rules. Current skill bindings and virtual models are configured
in `config.yaml`.

Comparisons must distinguish prompt benefit from routing/data defects and normal
model variance. The role's historical implementation is retained; closing the
campaign is **not a claim that it outperforms the general adaptive model**.
Multi-file attribution and coverage remain distinct concerns; see
[the closed coverage proposal](phase-43-kb-result-coverage.md).
