# Campaign 3 Phase 43 — Unscoped KB coverage proposal

**Closed 2026-10-27.** Historical contract; see the [campaign index](README.md).

**Closed without implementation.** The proposed measurement and per-file
head-coverage expansion are not a remaining campaign task and are not claimed
as shipped by the documentation cleanup.

The proposal distinguished two questions: whether pooled top-k hits contain
enough material from each relevant file, and whether an answer attributes each
claim to the file that actually supplied it. Clear filename attribution does not
guarantee balanced retrieval. Any future coverage design belongs in retrieval,
with explicit measurement, rather than adding filename knowledge to the generic
tool-payload truncator. A future request must reopen this as new scoped work.
