Search results and page reads are separate evidence paths. A failed page read
does not erase a successful search result's URL; a source renderer cannot recover
a URL the upstream worker never emitted. Tool names in prompts must exist in
the discovered tool registry.

This diagnostic led to the real [web page opener](phase-29-web-fetch-page-opener.md).
The retained retrieval lesson is that dense score distributions can overlap;
a global score threshold cannot perfectly separate topics. The proposed corpus
separation is closed as **not pursued in this campaign**. No historical tuning
receipt is a current instruction to change dataset topology.
